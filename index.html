I'm Karthikeyan Somasundaram, a Software Department Manager and LabVIEW engineer based in Tamil Nadu, India, leading the deployment team at Dynaspede Integrated Systems. My work lives at the intersection of software engineering and industrial hardware — writing code that controls real machines, measures real signals, and keeps real systems running.

Over the past 8+ years I've worked across the full stack of industrial automation: PC, PXI, cRIO, FPGA, and PC/PLC platforms. I've built everything from high-channel ATE systems for aircraft wiring to vector drive controllers for transmission test rigs. I believe in clean architecture, predictable deployments, and systems that work correctly every single time.

When I'm not debugging LabVIEW diagrams or reading oscilloscope traces, I follow cricket — especially Punjab Kings and CSK in the IPL — and continuously explore embedded systems design with microcontrollers like the PIC32.

Projects / Work

Things I've built & deployed

A selection of industrial automation and embedded systems projects.

01
Endurance Test Rig — Mahindra Transmission & Transaxle
Designed and developed test automation software to verify the functionality of Transmission & Transaxle by conducting endurance testing. Load applied at LH, RH and INPUT Motors at different steps. Auto-generated reports for each model.
LabVIEW NI cRIO-9066 Siemens S120 PROFINET TCP/IP UDP
02
Steering Gear Test Software — ZF India
Automated test sequence software for Hydraulic Power Steering validation. Driving Motor rotated at constant speed while Actuator applies load via profile setting. Captures angle, Torque and Pressure vs Torque parameters with auto-saved reports.
LabVIEW NI cRIO-9066 Siemens S120 MS SQL TDMS
03
Wiper Motor Test Software — Pricol CZEZ
Test automation software for endurance performance testing of Wiper Motor at various load conditions. Real-time data connected to cloud server. Detailed report generated at end of every test cycle. Integrated Barcode and Biometric scanners.
LabVIEW Siemens S7-1500 Siemens S120 Zebra Scanner Cloud
04
E-Vehicle Dynaliyser — OLA & Greaves Electrics
Production test rig for EV characteristics analysis. Bike drives motor at profile speed; RLS load simulates road load conditions on roller. Monitors speed, torque, regeneration power and brake force. Vehicle parameters captured via UDS & NI Xnet.
LabVIEW NI DAQ Siemens S120 NI Xnet UDS CAN
05
Endurance 3-Seater Test Platform — UNO-Minda
Test automation software for vehicle seat endurance testing. Back Rest and Head Rest loaded via hydraulic actuator. Analog output reference controls the actuator while monitoring angle and distance travelled, generating performance reports for the customer.
LabVIEW NI DAQ Hydraulic Actuator Analog I/O
06
EOL Transmission Load Test — Tata Motors
End-of-line test automation for transmission gearbox efficiency analysis, Shift Force quality and vibration. Robotic Gear Shifter engages gears during testing. Gearbox Vibration Analysis (harmonic, order analysis, order spectrum) done with auto-generated reports.
LabVIEW NI DAQ Siemens S120 Vibration Analysis Siemens 1500 PLC
07
Endurance Generator Test Platform — DRDO
Test automation software to verify the functionality of the Generator used in Fighter Jets. Developed AC & DC Load Bank APIs in LabVIEW 2020. Architecture and coding for LRU Controller data reading through CAN bus.
LabVIEW 2020 NI PXI Siemens S120 CAN Bus DRDO
08
PAL Video Signal Generator — cRIO FPGA
PAL 625i CVBS video signal generation on NI cRIO using NI 9401 with R-2R DAC ladder at 10 MHz clock. Full line and field timing implemented in FPGA clock ticks for cockpit display validation on a military display unit.
LabVIEW NI cRIO FPGA NI 9401 PAL 625i R-2R DAC
09
Cable Tester ATE — Multi-Channel Automated Test Equipment
Automated Test Equipment for cable and wiring harness testing covering multiple switching points. Custom hardware boards with shift-register relay control and a CAN backbone. LabVIEW GUI for test sequence execution, pass/fail reporting, and data logging.
LabVIEW ATE CAN Bus Relay Control Test Automation
10
RF Jamming Application — USRP
Software-defined RF jamming application developed using NI USRP hardware and LabVIEW. Configurable frequency, bandwidth, and jamming waveform parameters. Real-time signal transmission with live spectrum monitoring for testing and research purposes.
LabVIEW NI USRP SDR RF Signal Processing
11
ATC Simulation Application — USRP & LabVIEW
Air Traffic Control communication simulation using NI USRP software-defined radio and LabVIEW. Handles VHF band signal transmission and reception, frequency management, and real-time audio processing for ATC voice communication testing.
LabVIEW NI USRP SDR VHF ATC Signal Processing
